## Skua Mac

A native macOS version of the AQW bot client [VibeSkua](https://github.com/NinjaXz/VibeSkua) by NinjaXz
(built on [Skua](https://github.com/auqw/skua)), for Apple Silicon Macs.

### New in this version

- **Fixed (2.4.2):** opening Script Loader, Hotkeys and other windows a second time showed "The menu being updated does not match".
- **Fixed (2.4.1):** Skua Manager couldn't be closed. Closing its window or choosing Quit now exits it.
- **Account Manager:** Skua Mac menu > **Account Manager...** opens Skua Manager, where you can save accounts, put
  them in groups and start bots already logged in, with a script if you want.
- **Notifications:** get a Mac notification when a script stops or crashes, or your character dies. They only show
  while you're using another app. Choose them in Skua Mac menu > **Notifications** (the first time, allow
  notifications for Skua Mac; if none appear, turn them on in System Settings > Notifications > Skua Mac).
- **Mac menu bar:** Scripts, Options, Tools, Army and the rest are now also in the menu bar at the top of the screen,
  and **Settings...** (⌘,) is in the Skua Mac menu.
- **Windows remember where they were:** the Skua Mac bar and tool windows reopen where you left them. With several
  bots, each window keeps its own spot.
- **Fixed:** the game window could crash when Skua Mac quit, and its log filled up with repeated sound warnings.

**Install:** download the `.dmg` below, open it, and drag **Skua Mac** into Applications.

**First launch:** macOS will block it once because it isn't from the App Store. Open
System Settings > Privacy & Security, scroll down, and click **Open Anyway** next to Skua Mac.

**More bots:** Skua Mac menu > **New Skua Window** (⌘N). Each window is its own bot; use the **Army** menu to
control them all.

Botting is against AQW's rules. Use an alt account if you don't want to risk your main.
